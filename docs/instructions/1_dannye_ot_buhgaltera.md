# Инструкция 1. Какие данные нужны от бухгалтера

**Для кого:** бухгалтер (или тот, кто ведёт документы по аренде).
**Задача:** собрать данные по списку ниже и передать их владельцу. По этим данным
владелец заполнит бот учёта аренды.

**Как передать:** одной таблицей (Excel / Google Таблицы), по листу на каждый раздел.
Пересылайте файл лично, не в общие чаты: в нём ИНН, телефоны и суммы.

**Правила заполнения:**
- Суммы — в рублях, копейки через запятую: `50000` или `1562,40`.
- Даты — в виде `ДД.ММ.ГГГГ`: `01.03.2024`.
- Если значения нет — оставьте клетку пустой, ничего не придумывайте.
- Поля с пометкой **обязательно** нужны, без них запись в бот не внести.

## 4. Договоры аренды — по строке на каждый действующий договор

| № | Что нужно | Пример | Обязательно |

## 6. Общие параметры (один раз)

| № | Что нужно | Пример | Обязательно |
|---|---|---|---|
| 6.1 | Тариф на электроэнергию для арендаторов, ₽ за кВт·ч | 14 | да |
| 6.2 | Общий коэффициент к стоимости электричества (1 — без изменений) | 0,93 | да |
| 6.3 | Ставка пени за просрочку, % в день (по договорам) | 0,5 | да |
| 6.4 | Постоянный ежемесячный расход «Серверная», ₽ | 3000 | нет (0 — не учитывать) |
| 6.5 | Постоянный ежемесячный расход «Зарплаты», ₽ | 40000 | нет (0 — не учитывать) |

> Ставка пени в боте одна на всех. Если в договорах ставки разные — укажите это
> отдельной строкой, чтобы владелец знал.

## 7. Состояние расчётов на день начала учёта

По каждому договору за **текущий месяц**:

| № | Что нужно | Пример |
|---|---|---|
| 7.1 | Арендатор и помещение | ООО «Ромашка», Склад 3 |
| 7.2 | Аренда за текущий месяц оплачена? Сколько и когда | да, 50000, 03.11.2026 |
| 7.3 | Электричество за текущий месяц оплачено? Сколько | нет |
| 7.4 | Долг за прошлые месяцы (сумма и за что) | 12000 — аренда за сентябрь |

> Бот начинает считать с текущего месяца. Долги за прошлые месяцы в него
> автоматически не попадают — список из п. 7.4 нужен владельцу для контроля.

## 8. Расходы текущего месяца (если есть)

| № | Что нужно | Пример |
|---|---|---|
| 8.1 | Категория: командировочные / текущий ремонт / документация / налоги / прочее | Текущий ремонт |
| 8.2 | Сумма, ₽ | 15000 |

## Проверка перед отправкой

1. У каждого арендатора заполнены наименование, тип и ИНН.
2. У каждого договора есть номер, дата, сумма аренды и день оплаты.
3. У каждого сданного помещения есть литера.
4. У каждого счётчика есть последнее показание и месяц, за который оно снято.
5. Названия арендаторов и помещений в разделах 4, 5 и 7 написаны точно так же,
   как в разделах 2 и 3.
