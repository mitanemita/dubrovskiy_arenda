# Инструкция 2. Первичный ввод данных и запуск бота в работу

**Для кого:** владелец / оператор бота.
**Что понадобится:** таблица от бухгалтера (инструкция 1) и 1–2 часа времени.
**Результат:** бот знает все помещения, арендаторов, договоры и счётчики и сам
начисляет аренду, электричество и пеню.

---

## 0. Как устроен бот — прочитайте один раз

1. Откройте бот в Telegram и отправьте `/start`. Появится меню из четырёх кнопок:
   **🗂 Справочники · 💼 Учёт и финансы · 📝 Задачи · ⚙️ Настройки**.
2. Всё управление — кнопками под сообщением. Текст вы пишете, только когда бот
   просит что-то ввести (название, сумму, дату).
3. То, что вы написали, бот сразу удаляет из чата, а ответ показывает в том же
   сообщении — так и задумано, в чате не копится мусор.
4. Кнопка **✖️ Отмена** прерывает любой ввод и возвращает в меню.
5. Кнопка **⏭ Пропустить** появляется у необязательных полей.
6. Если что-то пошло не так — отправьте `/start`, меню откроется заново.
7. Форматы: суммы — `50000` или `1562,40`; даты — `01.03.2024`.

> ⚠️ Вводите данные строго в порядке шагов ниже. Договор нельзя создать, пока нет
> арендатора и помещения; счётчик — пока нет помещения.

---

## Шаг 1. Общие настройки

1. Нажмите **⚙️ Настройки**.
2. По очереди нажмите каждый параметр и введите число (из раздела 6 таблицы):
   1. **Тариф ₽/кВт·ч** — например `14`.
   2. **Коэффициент электричества** — например `0,93`. Если коэффициента нет — `1`.
   3. **Ставка пени, %/день** — например `0,5`.
   4. **Серверная, ₽/мес** — постоянный расход; `0`, если не нужен.
   5. **Зарплаты, ₽/мес** — постоянный расход; `0`, если не нужен.
3. После каждого значения бот ответит «✅ Значение сохранено».

## Шаг 2. Реквизиты арендодателя

1. **🗂 Справочники → 🏦 Реквизиты арендодателя**.
2. Нажимайте поле (Наименование, ИНН, КПП, …) и вводите значение из раздела 1 таблицы.
3. На расчёты это не влияет, но понадобится для квитанций — лучше заполнить сразу.

## Шаг 3. Помещения

Повторите для **каждого** помещения из раздела 2 таблицы (и сданных, и свободных):

1. **🗂 Справочники → 🏢 Помещения → ➕ Добавить**.
2. Введите **название** — например `Склад 3`.
3. Введите **литеру** — точно как на плане базы: `К1`, `Д`, `Е6`.
   - По литере помещение попадает на карту базы.
   - Можно пропустить, но тогда бот спросит литеру при создании договора.
4. **Адрес** — введите или нажмите «Пропустить».
5. **Площадь, м²** — введите или нажмите «Пропустить».
6. Бот ответит, что помещение добавлено.

Проверка: **🏢 Помещения → 📋 Все** — в списке должны быть все помещения.

## Шаг 4. Арендаторы

Повторите для **каждого** арендатора из раздела 3 таблицы:

1. **🗂 Справочники → 👤 Арендаторы → ➕ Добавить**.
2. Введите **наименование** — `ООО «Ромашка»`.
3. Выберите **тип** кнопкой: ИП / ООО / Физлицо.
4. Введите **ИНН** — 10 или 12 цифр, без пробелов.
5. **КПП** — 9 цифр для ООО; для ИП и физлиц нажмите «Пропустить».
6. **Адрес** — введите или пропустите.
7. **Email** — введите или пропустите.
8. **Телефон** — лучше ввести: он показывается в списке должников.

## Шаг 5. Договоры

Повторите для **каждого** действующего договора из раздела 4 таблицы:

1. **🗂 Справочники → 📄 Договоры → ➕ Добавить**.
2. Выберите **арендатора** кнопкой.
3. Выберите **помещение** кнопкой.
4. **Литера**: нажмите «✅ Оставить литеру …» или введите правильную.
5. Введите **номер договора** — `17/2024-АР`.
6. Введите **дату договора** — `01.03.2024`.
7. Введите **аренду в месяц** — `50000`.
8. Введите **день оплаты** (1–31) или пропустите — тогда будет 5-е число.

Что бот делает сразу после этого:
- помечает помещение как занятое;
- показывает арендатора на карте базы (по литере);
- начисляет аренду за текущий месяц.

> Один арендатор снимает два помещения — создайте два договора.

## Шаг 6. Счётчики

Только для помещений с оплатой электричества по счётчику (раздел 5 таблицы):

1. **🗂 Справочники → 🔌 Счётчики → ➕ Добавить**.
2. Выберите **помещение**.
3. **Серийный номер** — введите или пропустите.
4. **Название** — например `Основной`; или пропустите.
5. **Коэффициент** — вводите, только если у этого счётчика он свой. Иначе
   «Пропустить» — будет использоваться общий из настроек.

## Шаг 7. Начальные показания счётчиков

Это точка отсчёта: от неё бот будет считать расход.

1. **💼 Учёт и финансы → 🔢 Показания**.
2. Выберите счётчик.
3. Введите месяц и показание из п. 5.4–5.5 таблицы в виде `ММ.ГГГГ значение`,
   например: `10.2026 15230`.
4. Бот ответит: «Расход нулевой — начислять нечего (первое показание счётчика
   считается начальным)». Это правильно.
5. Повторите для каждого счётчика.

> Первое показание счётчика всегда начальное — по нему ничего не начисляется.
> Начисление появится со следующего показания.

## Шаг 8. Оплаты, которые уже пришли в этом месяце

По разделу 7 таблицы — для каждого арендатора, который уже заплатил:

1. **💼 Учёт и финансы → 💰 Отметить оплату**.
2. Выберите договор.
3. Нажмите начисление, например `Аренда 11.2026: 50000 ₽`.
4. Нажмите **✅ Оплатить полностью** — или введите сумму, если оплачено частично.

## Шаг 9. Расходы текущего месяца

По разделу 8 таблицы — для каждого расхода:

1. **💼 Учёт и финансы → 💸 Расходы → ➕ Добавить расход**.
2. Выберите категорию.
3. Введите сумму.

## Шаг 10. Итоговая проверка

1. **💼 Учёт и финансы → 🗺 Карта базы** — откройте присланный файл в браузере.
   - Все сданные помещения — синие, с правильным арендатором.
   - Если в подписи к файлу есть строка «⚠️ Нет на этом плане: …» — у этих помещений
     литера написана не так, как на плане. Исправьте: Справочники → Помещения →
     помещение → ✏️ Изменить → Литера.
2. **💼 Учёт и финансы → 📊 Отчёты**:
   - «Должников: N из M» — M должно равняться числу договоров.
   - **🔴 Должники** — в списке только те, кто действительно ещё не заплатил.
3. **🗂 Справочники → 📄 Договоры** — число договоров совпадает с таблицей.

Если всё сошлось — бот в рабочем состоянии. Дальше — инструкция 3 (ежемесячная работа).

## Частые ошибки при первом вводе

| Что видите | Причина | Что делать |
|---|---|---|
| «❌ ИНН — 10 или 12 цифр» | Лишние пробелы или буквы | Введите только цифры |
| «❌ Формат ДД.ММ.ГГГГ» | Дата написана иначе | Введите как `01.03.2024` |
| В списке при создании договора нет арендатора или помещения | Они ещё не заведены | Вернитесь к шагам 3–4 |
| Помещение не на карте | Нет литеры или она не как на плане | Исправьте литеру у помещения |
| Ошиблись в уже сохранённой записи | — | См. инструкцию 4, раздел «Исправления» |
