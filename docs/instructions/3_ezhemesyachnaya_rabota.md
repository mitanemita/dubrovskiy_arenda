# Инструкция 3. Ежемесячная работа с ботом

**Для кого:** владелец / оператор.
**Сколько времени:** 10–20 минут в месяц плюс минута на каждую пришедшую оплату.

---

## Что бот делает сам — вам ничего нажимать не нужно

| Когда | Что происходит |
|---|---|
| 1-го числа, 06:00 | По каждому действующему договору создаётся начисление аренды за новый месяц |
| 1-го числа, 06:00 | В расходы добавляются «Серверная» и «Зарплаты» (если заданы в настройках) |
| 1-го числа | Если у помещения есть счётчик без показаний за месяц — приходит сообщение-напоминание |
| Каждый день, 08:00 | У кого срок оплаты прошёл, а долг остался — начисляется и пересчитывается пеня |
| Каждый день, 08:00 | По задачам с близким сроком появляется счётчик «🔔 Уведомления по задачам» |
| Сразу при вводе показаний | Считается и начисляется электричество |

## Что делаете вы

| Когда | Что | Раздел ниже |
|---|---|---|
| Раз в месяц | Ввести показания счётчиков | 1 |
| Когда пришли деньги | Отметить оплату | 2 |
| Когда потратили | Записать расход | 3 |
| Раз в неделю | Посмотреть должников | 4 |
| В конце месяца | Посмотреть итог | 5 |

---

## 1. Показания счётчиков — раз в месяц

1. Откройте **💼 Учёт и финансы → 🔢 Показания**.
2. Нажмите счётчик. Бот покажет последнее показание.
3. Отправьте месяц и новое показание через пробел: `11.2026 15350`.
   - Месяц — тот, **за который** снято показание.
4. Бот ответит двумя строками:
   - «Расход: 120 кВт·ч»;
   - «⚡ Начислено электричество за 11.2026: 1562,40 ₽».
5. Повторите для каждого счётчика.

Как считается сумма: **расход × тариф × коэффициент**
(расход = новое показание − предыдущее).

Если ошиблись — просто введите показание за тот же месяц ещё раз. Бот заменит
запись и сам пересчитает начисление (и за следующий месяц тоже, если он уже введён).

> Если бот пишет «Текущие показания меньше предыдущих» или «Показания больше, чем
> за …» — проверьте цифру: показание не может быть меньше прошлого месяца и больше
> следующего.

## 2. Отметить оплату — каждый раз, когда пришли деньги

1. Откройте **💼 Учёт и финансы → 💰 Отметить оплату**.
2. Нажмите договор арендатора.
3. Бот покажет всё, что не оплачено, например:
   - `Аренда 11.2026: 50000 ₽`
   - `Электричество 11.2026: 1562,40 ₽`
   - `Пеня 11.2026: 250 ₽`
4. Выберите один из двух способов.

**Способ А — понятно, за что платёж (рекомендуется):**
1. Нажмите нужное начисление.
2. Заплатили всю сумму — нажмите **✅ Оплатить полностью**.
3. Заплатили часть — введите сумму цифрами.
4. Если платёж закрывает несколько строк (аренду и электричество) — повторите
   для каждой строки.

**Способ Б — пришла одна сумма «за всё»:**
1. Нажмите **💰 Произвольная сумма**.
2. Введите сумму.
3. Бот сам разнесёт её: сначала самые старые месяцы; внутри месяца — пеня, затем
   аренда, затем электричество.

Бот ответит «закрыто полностью» или покажет остаток долга.

> Если ввести сумму больше всего долга, излишек нигде не сохранится как аванс.
> Предоплату за будущий месяц отмечайте, когда появится начисление за этот месяц
> (1-го числа).

> ⚠️ Отметку оплаты нельзя отменить из бота. Перед вводом проверьте договор и сумму.
> Если всё же ошиблись — см. инструкцию 4, п. 3.4.

> Пеня перестаёт расти, как только аренда и электричество за месяц оплачены полностью.

## 3. Расходы — по мере появления

1. Откройте **💼 Учёт и финансы → 💸 Расходы → ➕ Добавить расход**.
2. Выберите категорию: Командировочные / Текущий ремонт / Документация / Налоги / Прочее.
3. Введите сумму.

Расход записывается в текущий месяц. «Серверная» и «Зарплаты» бот добавляет сам.

## 4. Кто должен — раз в неделю (или после срока оплаты)

1. Откройте **💼 Учёт и финансы → 📊 Отчёты → 🔴 Должники**.
2. По каждому должнику видно: арендатор, помещение, сумма долга, телефон и что
   именно не оплачено (аренда / электричество / пеня).
3. Позвоните или напишите арендатору. После оплаты — раздел 2.

## 5. Итог месяца — в последних числах

1. Откройте **💼 Учёт и финансы → 📊 Отчёты**. В сводке:
   - **Доход (оплачено)** — сколько денег получено по начислениям месяца;
   - **Расход** — все расходы месяца;
   - **Электричество (начислено)**;
   - **Должников: N из M** и общий долг.
2. **⚡ Электричество** — убедитесь, что нет строки «⏳ Нет замера за месяц».
   Если есть — введите показания (раздел 1).
3. **🏠 По помещениям** — сколько оплачено по каждому помещению за месяц.
4. **🗺 Карта базы** (в «Учёт и финансы») — актуальная картина занятости.

---

## Короткий чек-лист на месяц

- [ ] Показания по всем счётчикам введены
- [ ] Все пришедшие оплаты отмечены
- [ ] Расходы записаны
- [ ] Список должников просмотрен, с должниками связались
- [ ] В отчёте «Электричество» нет «Нет замера за месяц»
