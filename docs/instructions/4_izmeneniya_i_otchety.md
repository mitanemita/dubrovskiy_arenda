## 1. Новый арендатор, переезд, выезд

### 1.1. Появился новый арендатор
1. Если помещения ещё нет в боте: **🗂 Справочники → 🏢 Помещения → ➕ Добавить**.
2. **👤 Арендаторы → ➕ Добавить**.
3. **📄 Договоры → ➕ Добавить** — выберите арендатора и помещение.
4. Если платит по счётчику, а счётчика нет: **🔌 Счётчики → ➕ Добавить**, затем
   введите начальное показание (**💼 Учёт и финансы → 🔢 Показания**).

Подробно каждый шаг — в инструкции 2, шаги 3–7.

### 1.2. Арендатор переехал в другое помещение
1. **🗂 Справочники → 📄 Договоры** → нажмите договор.
2. **🏠 Сменить помещение** → выберите новое.
3. Старое помещение станет свободным, новое — занятым. Карта обновится.

### 1.3. Арендатор съехал
1. Сначала отметьте все его оплаты (инструкция 3, раздел 2).
2. **🗂 Справочники → 📄 Договоры** → договор → **🗑 Удалить договор** → подтвердите.
3. Помещение станет свободным. Новые начисления создаваться не будут.

> ⚠️ Удаление договора необратимо. Если по договору остался долг — сначала
> запишите его себе: после удаления он пропадёт из отчёта по должникам.

### 1.4. Удалить арендатора, помещение или счётчик
Откройте карточку в соответствующем списке → кнопка **🗑 Удалить …** → подтвердите.
Удаляйте только то, что заведено по ошибке или больше не нужно.

## 2. Изменились условия

| Что изменилось | Куда нажать |
|---|---|
| Сумма аренды | Справочники → Договоры → договор → **✏️ Аренда ₽** → новая сумма |
| День оплаты | Справочники → Договоры → договор → **📅 День оплаты** → число 1–31 |
| Название, ИНН, КПП, адрес, email, телефон арендатора | Справочники → Арендаторы → арендатор → кнопка с названием поля |
| Название, литера, адрес, площадь помещения | Справочники → Помещения → помещение → **✏️ Изменить** → поле |
| Реквизиты арендодателя | Справочники → 🏦 Реквизиты арендодателя → поле |
| Тариф, коэффициент, ставка пени, постоянные расходы | ⚙️ Настройки → параметр |

Важно:
- Новая сумма аренды действует **со следующего начисления**. Начисление за текущий
  месяц уже создано — если его тоже нужно изменить, см. п. 3.1.
- Новый тариф применяется к показаниям, которые вы вводите после изменения.
- Новая ставка пени действует со следующего ежедневного пересчёта.

## 3. Исправление ошибок

### 3.1. Неверная сумма начисления (аренда, электричество, пеня)
1. **🗂 Справочники → 📄 Договоры** → договор → **💵 Начисления (правка)**.
2. Кнопками «◀️ Пред. месяц / След. месяц ▶️» выберите месяц.
3. Нажмите номер строки.
4. Введите правильную сумму.
5. Введите причину (например, «скидка по соглашению»).

Исправление записывается в журнал: кто, когда, было/стало, причина.

### 3.2. Неверная сумма расхода
1. **💼 Учёт и финансы → 💸 Расходы → 📋 Расходы месяца (правка)**.
2. Выберите месяц, нажмите номер расхода.
3. Введите правильную сумму и причину.

> Удалить расход нельзя. Если он внесён по ошибке — исправьте сумму на `0`.

### 3.3. Неверные показания счётчика
Введите показание за тот же месяц ещё раз (инструкция 3, раздел 1). Запись
заменится, электричество пересчитается автоматически.

### 3.4. Ошибочно отметили оплату
Отменить платёж из бота нельзя. Что можно сделать:
1. Оплату отнесли не на то начисление, но сумма у арендатора верная — оставьте:
   общий долг арендатора считается правильно.
2. Отметили лишнюю сумму или не тому арендатору — нужна правка в базе данных.
   Обратитесь к тому, кто обслуживает бот.

### 3.5. Опечатка в названии, ИНН, литере
См. таблицу в разделе 2.

## 4. Отчёты

Все отчёты: **💼 Учёт и финансы → 📊 Отчёты**. Сначала открывается сводка за
текущий месяц.

| Кнопка | Что показывает |
|---|---|
| (сводка) | Доход (оплачено), расход, начисленное электричество, число должников и долг |
| **🏠 По помещениям** | Сколько оплачено по каждому помещению за выбранный месяц |
| **⚡ Электричество** | Расход по помещениям, оплачено или долг, у кого нет замера |
| **🔴 Должники** | Кто должен, сколько, за что, телефон |
| **📅 Другой месяц** | Выбор года и месяца — те же отчёты за прошлый период |

Как читать сводку:
- **Доход** — деньги, полученные по начислениям этого месяца. Оплата ноябрьской
  аренды, пришедшая в декабре, попадёт в доход ноября.
- **Должников: 2 из 15** — у двух из пятнадцати договоров есть неоплаченный остаток.

Расходы месяца списком: **💸 Расходы → 📋 Расходы месяца (правка)**.

## 5. Карта базы

1. В карточках помещений Краснодара выберите **🗺 Площадка → Краснодар**.
   Помещения других городов привяжите к их площадкам; без привязки помещение не
   отображается на плане. Литеру указывайте как на плане.
2. **💼 Учёт и финансы → 🗺 Карта базы**.
3. Бот пришлёт файл `Karta-….html`. Откройте его в браузере (на телефоне —
   «Открыть в…» → браузер).
4. Цвета:
   - ⚪ белый пунктир — нет подтверждённых данных;
   - 🔵 синий — арендовано;
   - 🟢 зелёный — свободно и готово к сдаче;
   - 🟠 оранжевый — не готово к сдаче;
   - ⚫ серый — не сдаётся; ⚙️ светло-серый — техническое; 🔴 красный — стройка.
5. Нажмите на литеру на карте — откроется описание: арендатор, площадь, аренда.
6. **🔄 Обновить** под файлом — пересобрать карту после изменений.

Арендатор и аренда на карте берутся из действующего договора — по **литере**
помещения, привязанного к Краснодару. В карточке помещения кнопкой «Готовность»
выберите состояние, а через «Изменить» задайте площадь и предполагаемую ставку.
Фактическая ставка рассчитывается по арендной плате и площади из учёта, а не по
площади из шаблона плана. Для остальных площадок планов пока нет.
«⚠️ Нет на этом плане: …» в подписи значит, что литера помещения в боте
не совпадает с литерой на плане (п. 2, «литера помещения»).

> Файл карты содержит фамилии арендаторов и суммы аренды. Не пересылайте его
> посторонним.

## 6. Задачи

**📝 Задачи** — список дел с напоминаниями. С деньгами не связан.

### 6.1. Добавить одну задачу
1. **📝 Задачи → ➕ Задача**.
2. Введите текст.
3. Выберите, кому: Митя / Алексей / «Ввести имя» / «Общая».
4. Выберите срок:
   - 🔴 1 — срочно, 3 дня;
   - 🟡 2 — 7 дней;
   - 🟢 3 — 25 дней;
   - 📅 На дату — ввести конкретную дату.

### 6.2. Добавить несколько задач сразу
1. **📝 Задачи → ➕ Списком**.
2. Отправьте одним сообщением, по задаче на строку. В конце строки — приоритет
   `1`/`2`/`3` или дата:
   ```
   Позвонить электрику 1
   Уборка территории 3
   Вывоз камней литера А 15.12.2026
   ```
   Без цифры в конце — приоритет 2.

### 6.3. Посмотреть и изменить
- **📋 Ближайшие** — 10 задач с ближайшим сроком.
- **✏️ Редактировать** → номер задачи → карточка с кнопками:
  ✅ Выполнено · 🗑 Удалить · 🏷 Категория (новый срок) · 📅 Дата · 👤 Адресат.
- **✅ Выполненные** — архив; нажмите номер, чтобы удалить из архива.

### 6.4. Цвета и уведомления
- Кружок у задачи — сколько осталось до срока: ⚫ просрочена, 🔴 до 3 дней,
  🟡 до 7, 🟢 до 25, 🔵 больше.
- Когда срок близко, вверху любого меню появляется «🔔 Уведомления по задачам: N».
- **📝 Задачи → 🔔 Уведомления** — список; нажмите номер, чтобы открыть задачу.
  «✅ Прочитать все» сбрасывает счётчик.

## 7. Настройки

**⚙️ Настройки** → параметр → новое число.

| Параметр | На что влияет |
|---|---|
| Тариф ₽/кВт·ч | Стоимость электричества для арендаторов |
| Коэффициент электричества | Множитель к стоимости (для счётчиков без своего коэффициента) |
| Ставка пени, %/день | Пеня = неоплаченные аренда и электричество × ставка × дни просрочки |
| Серверная, ₽/мес | Автоматический расход 1-го числа |
| Зарплаты, ₽/мес | Автоматический расход 1-го числа |

Чтобы пеня не начислялась вообще — поставьте ставку `0`.

## 8. Доступ и безопасность данных

1. Бот отвечает только тем, чей Telegram ID указан в настройках сервера
   (`ADMIN_IDS`). Посторонний на любую команду и кнопку получит «⛔ Доступ запрещён».
2. Добавить или убрать оператора может только тот, кто обслуживает сервер.
3. Не пересылайте посторонним сообщения бота, файл карты и таблицу бухгалтера —
   в них ИНН, телефоны и суммы.
4. Включите в Telegram двухэтапную аутентификацию (Настройки → Конфиденциальность):
   кто получит доступ к вашему Telegram, получит доступ и к боту.
5. Не публикуйте токен бота и файл `.env` с сервера.

## 9. Если бот не отвечает или ведёт себя странно

1. Отправьте `/start` — меню откроется заново, незаконченный ввод сбросится.
2. Бот написал «⚠️ Произошла ошибка. Действие отменено» — повторите действие с
   начала. Если повторяется — запомните, что нажимали, и сообщите тому, кто
   обслуживает бот.
3. Бот молчит дольше пары минут — он выключен на сервере. Сообщите тому, кто
   обслуживает сервер.
4. `/version` — показывает версию бота; пригодится при обращении за помощью.
