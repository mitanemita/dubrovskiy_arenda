# Работа с проектом и актуальная версия

- Перед изменениями изучите `HANDOFF.md`, затем проверьте состояние рабочей копии,
  `git fetch origin --prune`, все удалённые ветки и открытые pull request'ы.
  Документация, default branch и `main` могут отставать от реально работающей версии.
- Выясните, какая версия установлена: `/version` в боте выводит ветку и коммит.
  Сопоставьте его с историей Git и выберите основу, содержащую работающий код и
  последние изменения пользователя. Если это невозможно определить по данным,
  запросите `/version` у пользователя; не объявляйте выбор ветки доказанным.
- Версия сокращённого меню и учёта включена в историю `main` через PR #9;
  её исходный коммит — `b43a57b`. Перед развёртыванием проверьте историю
  целевой ветки и наличие всех изменений, установленных на сервере. Сведения
  в этой инструкции не подтверждают текущую версию сервера: её нужно проверить.
- Сохраняйте все пользовательские изменения. Не переносите старую реализацию
  поверх новой, не переписывайте ветки и не выполняйте `git reset --hard` или
  очистку данных для решения проблем с версией. Для интеграции используйте PR,
  проверяйте его diff и запускайте соответствующие тесты.
- Перед развёртыванием сопоставьте работающий коммит с целевым (`git merge-base
  --is-ancestor <running> <target>`). При неустановленной, несвязанной или более
  новой версии выясните расхождение и сначала объедините изменения. Не обходите
  проверку без явного согласия пользователя. Публикация кода и запуск на сервере —
  разные действия; всегда сообщайте, выполнены ли они.
- При правках интерфейса повышайте `BOT_UI_VERSION` и проверяйте `/version` после
  развёртывания. Инструкция по установке должна учитывать, что старая версия
  `deploy.sh` ещё не содержит защиту от отката.
